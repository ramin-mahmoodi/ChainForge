# ChainForge ⚡

> **V2Ray / Xray Proxy Chain Configuration Builder**  
> ابزار مدرن، سریع و کاملاً کلاینت‌ساید برای ساخت زنجیره اتصال پروکسی‌های V2Ray و Xray.

---

## ✨ قابلیت‌ها (Features)

- **پشتیبانی از پروتکل‌های مختلف:**
  - VLESS (با پشتیبانی از REALITY، Vision، xHTTP، WebSocket و gRPC)
  - VMess (رمزگشایی خودکار Base64 و ساخت کامل کانفیگ)
  - Trojan (با لایه‌های TLS، REALITY و xHTTP)
  - SOCKS5 و HTTP Proxy
  - ورودی بلوک‌های استاندارد JSON و لینک‌های Base64
- **امنیت ۱۰۰٪ و محلی (Client-Side):**
  - تمامی عملیات پارس و ساخت زنجیره در مرورگر شما انجام می‌شود و هیچ اطلاعاتی به سرور خارجی ارسال نمی‌گردد.
- **تشخیص هوشمند پروتکل (Auto Detection):**
  - شناسایی خودکار نوع لینک و اعتبارسنجی زنده.
- **طراحی مدرن و واکنش‌گرا:**
  - پشتیبانی از تم تاریک (Dark Mode) و تم روشن (Light Mode).
  - کلیدهای میانبر (Ctrl + Enter برای ساخت سریع کانفیگ).
  - کپی مستقیم و دانلود فایل config.json.
