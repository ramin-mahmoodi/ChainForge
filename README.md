## معرفی

**ChainForge** یک ابزار تحت وب مدرن، متمرکز و کاملاً سمت کاربر (Client-Side) است که به شما امکان می‌دهد لینک‌های سرور پروکسی مختلف خود را به ترتیب دلخواه کنار هم قرار داده و یک فایل پیکربندی استاندارد `config.json` چندمرحله‌ای (Multi-Hop Proxy Chain) برای هسته‌های **Xray** و **V2Ray** تولید کنید.

در ساختار اتصال زنجیره‌ای:
- ترافیک دستگاه شما ابتدا وارد یک پورت ورودی محلی (Inbound) روی رایانه یا گوشی می‌شود.
- سپس به سرور نخست (**ورودی / Entry**) متصل می‌شود.
- در صورت وجود، ترافیک از سرورهای میانی (**واسطه / Relay**) عبور می‌کند.
- در پایان از طریق سرور نهایی (**خروجی / Exit**) به اینترنت آزاد متصل می‌گردد.

این رویکرد سبب پنهان ماندن سرور اصلی خروجی، بهبود پایداری اتصال در شرایط اختلال شبکه و افزایش چشمگیر حریم خصوصی می‌شود.

## ویژگی‌ها و امکانات

### ۱. پردازش ۱۰۰٪ درون مرورگر و بدون ذخیره‌سازی داده (Privacy-First)
تمام عملیات تجزیه و تحلیل لینک‌ها، اعتبارسنجی پارامترها و تولید فایل JSON منحصراً داخل مرورگر کاربر انجام می‌گیرد. هیچ داده، آی‌پی، توکن یا لینکی به سرورهای خارجی ارسال یا در جایی ذخیره نمی‌شود.

### ۲. پشتیبانی دو زبانه کامل (انگلیسی و فارسی)
- سوئیچ سریع زبان با کلید لغزنده (`EN` / `فا`)
- پشتیبانی بومی از راست‌چین (RTL) و چپ‌چین (LTR)
- نمایش اعداد و شمارنده‌ها متناسب با زبان انتخابی
- ذخیره‌سازی ترجیحات زبان و تم در مرورگر بدون پرش هنگام بارگذاری

### ۳. جابجایی هوشمند و مرتب‌سازی درگ اند دراپ (Drag & Drop)
- امکان تغییر ترتیب سرورها با کشیدن دستگیره جابجایی (`:::`) یا استفاده از کلیدهای جهت‌دار کیبورد
- دکمه‌های درج سریع (`+`) برای اضافه کردن سرور جدید در ابتدای مسیر یا میان هر دو مرحله

### ۴. تنظیمات پیشرفته (Advanced Settings)
- **پورت SOCKS محلی**: تنظیم پورت کلاینت محلی (پیش‌فرض: `10808`)
- **پورت HTTP محلی**: تنظیم پورت وب پروکسی محلی (پیش‌فرض: `10809`)
- **سطح لاگ هسته (Log Level)**: انتخاب سطح گزارش‌گیری بین `warning`، `none`، `error`، `info` و `debug`
- **بای‌پس شبکه محلی (Bypass LAN)**: هدایت مستقیم ترافیک آدرس‌های خصوصی (مانند `192.168.x.x` یا `10.x.x.x`) بدون عبور از زنجیره با استفاده از `geoip:private`

### ۵. پشتیبانی جامع از پروتکل‌های ارتباطی
- **VLESS**: با لایه‌های امنیتی REALITY، TLS، Vision (XTLS) و انواع انتقال شبکه شامل xHTTP (SplitHTTP)، WebSocket، gRPC، HTTP/2 و TCP.
- **VMess**: رمزگشایی خودکار متادیتا از فرمت Base64 و پشتیبانی از انواع شبکه و امنیت.
- **Trojan**: پشتیبانی کامل از REALITY، TLS و انواع انتقال.
- **SOCKS5 و HTTP**: سازگار با پروکسی‌های محلی و سرورهای واسط.
- **JSON Outbounds**: امکان چسباندن مستقیم بلوک‌های تنظیمات خام JSON.

### ۶. تجربه کاربری روان
- کلید میانبر کیبورد (<kbd>Ctrl + Enter</kbd> یا <kbd>Cmd + Enter</kbd>) برای ساخت سریع کانفیگ
- کپی سریع در کلیپ‌بورد و دانلود فایل JSON با نام‌گذاری متناسب با تعداد هاپ‌ها
- نمایش برچسب پروتکل‌ها، آدرس، پورت و اعتبارسنجی آنی خطاها
- تشخیص وضعیت منقضی‌شدن (Outdated) در صورت تغییر لینک‌ها پس از ساخت

## راهنمای گام‌به‌گام استفاده

### مرحله ۱: افزودن سرورها
1. لینک سرور ورودی (Entry) و سرور خروجی (Exit) را در کادرهای متناظر وارد کنید.
2. با کلیک بر روی دکمه «چسباندن» می‌توانید مستقیماً از کلیپ‌بورد پیست کنید.
3. در صورت نیاز به سرورهای بیشتر، روی دکمه «افزودن هاپ» یا علامت‌های `+` میان مراحل کلیک کنید.
4. ترتیب سرورها را می‌توانید با دستگیره کشیدن (`:::`) جابجا نمایید.

### مرحله ۲: اعمال تنظیمات دلخواه (اختیاری)
روی گزینه **«تنظیمات پیشرفته»** کلیک کنید:
- پورت‌های SOCKS و HTTP را در صورت نیاز به پورت‌های دلخواه تغییر دهید.
- در صورت تمایل، گزینه «ترافیک شبکه‌ی محلی مستقیم برود» را فعال نگه‌دارید تا ارتباط با دستگاه‌های داخل مودم/شبکه قطع نشود.

### مرحله ۳: ساخت کانفیگ
دکمه **«ساخت کانفیگ»** را بزنید (یا کلیدهای ترکیبی <kbd>Ctrl + Enter</kbd> را بفشارید).

### مرحله ۴: بارگذاری در نرم‌افزارهای کلاینت
فایل JSON تولید شده را دانلود کنید یا متن آن را کپی کرده و در کلاینت مورد نظر خود وارد نمایید:

| سیستم‌عامل | نرم‌افزارهای پیشنهادی | نحوه استفاده |
| :--- | :--- | :--- |
| **ویندوز** | **v2rayN** / **Nekoray** | در v2rayN از منوی `Servers` گزینه `Add custom config server` را بزنید و فایل JSON را انتخاب کنید. در Nekoray از منوی `Program` گزینه `Add profile from custom config` را انتخاب کنید. |
| **اندروید** | **v2rayNG** / **NekoBox** | در v2rayNG از علامت `+` گزینه `Import config from custom / file` را انتخاب کرده و فایل دانلود شده را باز کنید. |
| **لینوکس** | **Nekoray** / **Xray Core CLI** | اجرای مستقیم فایل با دستور `xray run -config config.json` یا درون رابط کاربری گرافیکی Nekoray. |
| **مک (macOS)** | **V2rayU** / **FoXray** | انتخاب گزینه Import Custom Config در تنظیمات برنامه. |
| **iOS** | **Streisand** / **FoXray** | ایمپورت مستقیم فایل یا پیست کردن محتوای JSON در بخش تنظیمات سفارشی. |

## توسعه و اجرای محلی (Local Development)

در صورتی که می‌خواهید پروژه را به صورت محلی بر روی رایانه خود اجرا و ویرایش کنید:

```bash
# کلون کردن مخزن
git clone https://github.com/ramin-mahmoodi/ChainForge.git
cd ChainForge

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# ساخت بیلد نهایی برای انتشار
npm run build
```
